# Задание 3 — модели на Raspberry Pi 5

Основной отчёт с кодом, результатами и графиками:
`Egor_Bykov_task_3.ipynb`.

В работе выполнены экспорт LeNet и MobileNetV3 в ONNX,
статическая квантизация, сравнение серверного исполнения
с Raspberry Pi 5 и эксперименты с детектором YOLOv8n.

## Файлы

- `hw3/summary.csv` — сводная таблица измерений.
- `hw3/*.json` — метаданные моделей и результаты проверок.
- `hw3/*.log`, `hw3/*_uptime.txt` — сохранённый вывод измерений.
- `hw3/*_server.npy`, `hw3/*_pi.npy` — предсказания на одинаковых входах.
- `hw3/detection_results/` — результаты детекции.
- `images/` — иллюстрации отчёта.

Сохранены LeNet FP32/INT8, MobileNetV3 INT8 и смешанный
MobileNetV3 с depthwise-свёртками в FP32.

Тяжёлые модели стенда, исходный MobileNetV3 FP32 и большой
набор входов Flowers102 не включены. Они используются
или создаются при выполнении ноутбука.

## Окружения

- Учебный сервер: x86_64, ONNX Runtime 1.31.0.
- Raspberry Pi 5: aarch64, ONNX Runtime 1.29.0.

Пути в ноутбуке соответствуют учебному серверу.
Для повторного запуска в другом окружении их нужно адаптировать.
Обучающие данные и веса из предыдущих заданий подготавливаются отдельно.
